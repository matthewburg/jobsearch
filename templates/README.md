# Templates

Blank starting files for a new person's setup. Copy `profile/` and `samples/` into the kit folder, then fill them in with Claude (see [../SETUP.md](../SETUP.md)).

- `profile/`: the experience bank and search settings. Everything the job finder and the resume writer read.
- `samples/`: a drop zone for past resumes, cover letters, and recommendations, kept as-is.

`python -I job-finder/install.py` does the copying for you and never overwrites files you've already filled in.
